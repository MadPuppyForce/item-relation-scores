Ce dépôt accompagne l’article Scores de substituabilité et de complémentarité entre items pour l’évaluation des systèmes de recommandation (Griffon, Delestre, Guériau, Zanni-Merk). Il contient, dans le dossier resultats/, les tables de scores obtenues lors des deux expérimentations de l’article : les classements de substituts sur le jeu de données INCA2 (sessions de petit-déjeuner et de déjeuner, puis séparées par type de repas) et les paires de substituabilité et de complémentarité identifiées sur le jeu de données BundleRec (électronique, habillement, alimentation). Les scores comparés sont le score de substituabilité d’Akkoyunlu et al. (2017), l’Item Co-occurrence (IC) de Sun et al. (2017) et les scores proposés dans l’article.
